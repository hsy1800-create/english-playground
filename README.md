# 영어 놀이터

천재(함순애) 초등 영어 4학년 6단원 `Where’s My Cap?` 학습 표현을 활용한 비공식 수업용 게임입니다. 교과서 PDF, 원본 그림, 음원은 포함하지 않습니다.

## 두 가지 수업 방식

- **PPT 모드**: 학생 기기 없이 교실 화면으로 진행합니다. 정답 공개, 이전·다음 장, 팀별 점수, 전체 화면을 지원합니다. 방향키와 스페이스로 진행할 수 있습니다.
- **QR 참여 모드**: 교사가 수업 방을 만들고 참여 QR을 띄웁니다. 학생은 QR을 스캔하고 별명으로 참여합니다. 6자리 코드 입장도 가능합니다. 교사가 정답 공개와 다음 문항을 진행합니다.

## 실행

`index.html`을 브라우저로 열거나 GitHub Pages 주소로 접속합니다. PPT 모드는 별도 서버가 필요 없습니다. QR 모드는 인터넷과 연결된 수업 서버를 사용합니다.

공개 주소: https://hsy1800-create.github.io/english-playground/

## 활동

그림·단어 연결, 철자 배열, 빈칸 채우기, 문장 뜻 고르기, 그림 탐정, 위치 찾기, 듣고 찾기, 문장 조립, 기억 도전, 대화 완성, 짝 미션을 제공합니다. 6단원 복습 17문항과 단원 밖 그림 도전 6문항을 제공합니다. 그림 수수께끼는 선택지 없이 먼저 추리하고, 필요할 때 힌트를 엽니다. 학생은 영어 답을 직접 입력할 수 있습니다.

## 서버와 데이터

QR 수업은 `https://cap-detectives-grade4-hsy.edupro10855.chatgpt.site`의 공개 API를 사용합니다. GitHub Pages는 화면을 호스팅하며 수업 방·답안 데이터는 해당 서버가 처리합니다. 학생은 실명 대신 별명을 사용할 수 있습니다. 수업 방은 생성 후 24시간 동안 입장 가능합니다. 자동 데이터 삭제 기능은 아직 없습니다.

정답이 포함된 학습 게임이므로 시험·공식 평가 용도로 설계하지 않았습니다. 브라우저 음성 합성의 지원 여부와 목소리는 기기에 따라 다릅니다.

## 직접 제작한 그림

해 + 꽃, 이 + 솔, 발 + 공, 버터 + 파리, 침대 + 방, 사과 + 주스의 조합을 새로 그렸습니다. 그림 도전은 교과서 필수 어휘를 넘어서는 보너스 활동입니다. 그림은 HTML에 포함되어 별도 이미지 서버 없이 표시됩니다.
